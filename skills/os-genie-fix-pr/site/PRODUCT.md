# Product: PR log

Register: public personal page (Read mode).

What it is: a log of the pull requests the owner has sent to other people's open source projects, with what happened to each.
Audience: anyone who lands on it. They should understand it in ten seconds without knowing what a pull request tracker is.
Job: show the record honestly (open, merged, closed), and show what the owner still has to do.
Constraints: no framework, no build step, three static files plus data.json, works on a phone, accessible (keyboard, screen reader, contrast, reduced motion), easy to edit by hand.
Content truth: every number and title comes from data.json, written by ledger.py. Nothing is invented. No claims about quality or skill.
Voice: first person, plain, short sentences. No marketing words, no emoji, no dashes, no semicolons in prose.
