# Evidence: why this repo scoring works

1. **Signal weights mirror validated tooling.** `gh-analyzer` scores repos 0-100 across commit momentum 30%, bus factor 25% (HHI concentration), issue resolution 20%, PR latency 15%, release cadence 10%, with letter grades. This skill adopts those weights so scorer output stays comparable to an installable tool. Source: `pypi.org/project/gh-analyzer`.
2. **Maintainer availability dominates.** LFX Insights Health Score: Maintainer Health 28/40, Security & Supply Chain 31/35, Development Activity 15/25, with bus factor (active merge-rights holders), org diversity, and median response time as first-class inputs. Single-maintainer projects stall regardless of stars. Source: `insights.linuxfoundation.org`.
3. **Sample weekly, use medians.** Adejumo & Johnson, "An Empirical Validation of Open Source Repository Stability Metrics", arXiv Aug 2025 (100 top GitHub repos, CSI framework): daily commit-stability criteria fail for ~98% of repos (bursty behavior); weekly sampling is feasible; swapping mean→median for resolution/review times improves stability inference. This skill's momentum + latency dimensions follow that prescription.
4. **Community health is multi-signal.** CHAOSS metrics (chaoss.community/metrics): conversion rate, issue age, change-request closure ratio, new-vs-returning contributors, responsiveness. No single number suffices: hence five dimensions, not one.
5. **Contributor loop quality predicts abandonment.** GoodFirstIssue.org maintainer guide: recommendations work when repos show active maintenance, clear issue writing with acceptance criteria, small reviewable scope, and runnable tests + responsive feedback. Repos failing that loop produce abandoned PRs even from good contributors.
6. **Green CI + test docs merge faster.** MSR 2026 agentic-PR study (AIDev, ~933k PRs): test-containing PRs trend larger/slower but merge similarly; docs/CI/build tasks merge 74-84%. OSS documentation study 2025-26 (160 repos): how-to-run/write-tests docs correlate with test engagement ρ≈0.34-0.36, TER mean 0.37. Prefer repos with CONTRIBUTING test instructions + green CI.
7. **Use the project first.** Maintainer interview wisdom (opensource.guide; open-source-contribution skill): contributions to tools you use have the highest hit rate; cold "showing up" has the lowest. Break ties toward repos in the user's stack.
